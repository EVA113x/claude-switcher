# Shadowrocket 修复 - 正确安装方式

## ⚠️ 重要：环境变量传递

`open xxx.command` **不会**传递环境变量到新 Terminal 进程。必须直接在 Terminal 中运行。

---

## ✅ 方法 1: 直接终端运行(推荐)

```bash
# 1. 解压部署包
cd ~/Downloads
tar -xzf shadowrocket-fix-deployment.tar.gz
cd claude-switcher  # 如果解压到子目录

# 2. 设置客户端并运行(在同一 shell 中)
CLAUDE_PROXY_CLIENT=shadowrocket bash installer/安装.command
```

**说明**: 
- 环境变量和 bash 在同一命令,确保传递
- 保持正常 sudo 交互
- 适用于所有客户端: `shadowrocket`, `clash-verge`, `flclash`, `sing-box`, `clashx`, `surge`, `auto`

---

## ✅ 方法 2: 已安装用户快速修复

```bash
# 1. 解压并替换核心脚本
cd ~/Downloads
tar -xzf shadowrocket-fix-deployment.tar.gz
cp claude-switcher/core/claude-switch.sh ~/.local/bin/
chmod +x ~/.local/bin/claude-switch.sh

# 2. 切换并同步(需输入密码)
~/.local/bin/claude-switch.sh set-client shadowrocket --sync

# 3. 验证
~/.local/bin/claude-switch.sh checkdetail | grep "保镖"
# 应显示: 保镖=ok:... (不应有 "客户端不一致")
```

**限制**:
- `--sync` 只能更新**已安装**的保镖
- 如果保镖未安装,必须先运行方法 1 完整安装

## ✅ 方法 3: 无环境变量(手动选择)

如果不方便设置环境变量:

```bash
cd ~/Downloads
tar -xzf shadowrocket-fix-deployment.tar.gz
cd claude-switcher
bash installer/安装.command
```

安装器会:
1. 检测运行中的代理客户端
2. 如检测到多个,提示您选择
3. 如都未运行,检测配置目录
4. 最后回退到手动选择菜单

## 📋 验证清单

```bash
# 1. 完整检查(不应有"客户端不一致")
~/.local/bin/claude-switch.sh checkdetail

# 预期输出:
# 代理内核=ok:Shadowrocket 已连接
# ...
# 保镖=ok:待命  ← 不应显示 "fail:客户端不一致"

# 2. 配置一致性
grep '^PROXY_MODE=' ~/.local/bin/claude-switch.sh
# 输出: PROXY_MODE="shadowrocket"

sudo grep '^MODE=' "/Library/Application Support/claude-switcher/claude-bodyguard.sh"
# 输出: MODE="shadowrocket"
# 两者应相同

# 3. 保镖服务运行
launchctl print system/local.claude-bodyguard | grep state
# 输出: state = running
```

## ❌ 错误的方式

```bash
# ❌ 不要这样做(环境变量不会传递)
export CLAUDE_PROXY_CLIENT=shadowrocket
open installer/安装.command

# ❌ 不要这样做(双击不会传递环境变量)
# 在 Finder 中双击 安装.command
```

**原因**: macOS 的 `open` 命令会创建新的独立进程,不继承当前 shell 的环境变量。

## 🔧 方法 2 的限制说明

`set-client --sync` 的设计约束:
- ✅ 可以更新已安装的保镖
- ❌ 不能全新安装保镖(需要先运行安装器)

**为什么**: 保镖安装涉及:
- 从模板物化脚本(`daemons/claude-bodyguard.sh`)
- 替换 `__HOME__` / `__PROXY_MODE__` 等占位符
- 安装 LaunchDaemon plist
- 完整的 root 目录结构创建

`--sync` 只做原子更新现有文件,不处理这些初始化步骤。

**如果保镖未安装**:
```bash
~/.local/bin/claude-switch.sh set-client shadowrocket --sync
# 输出:
# FAIL:保镖尚未安装,--sync 只能更新现有保镖
# INFO:请先运行安装器完成初始安装,再使用 --sync 切换客户端

# 正确做法:
cd ~/Downloads/claude-switcher
CLAUDE_PROXY_CLIENT=shadowrocket bash installer/安装.command
```
